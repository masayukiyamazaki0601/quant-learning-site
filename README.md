# Quant Learning — 1年52週のクオンツ学習サイト（自分用）

金融クオンツ1年カリキュラムに基づく自分用の理解サイト。
**1ユニット = 1週間** の粒度で、数学・金融工学・Python/C++の学習内容とアウトプットを
1ページずつHTMLで積み上げていく。数式の手写しはしない運用（AIが下書き → 読んで自分の言葉に直す）。

## 起動方法

```bash
cd quant-learning-site
python3 -m http.server 8000
# → http://localhost:8000/
```

- MathJax・Google Fonts はCDN参照のためインターネット接続が必要。
- ブラウザで直接 `index.html` を開いても動く（file:// 動作可）。

## サイト構成

```
quant-learning-site/
├── index.html        # トップ（hero・使い方・カリキュラム目次）
├── phase-1.html      # フェーズ概要（第1〜13週）… phase-4.html まで
├── p1-01.html …      # ユニットページ（未作成。作ったものから追加する）
├── css/
│   ├── style.css     # ベース（配色・タイポ・ヘッダ/フッタ・テーブル等）
│   ├── toc.css       # index.html（目次）用
│   └── lesson.css    # ユニット/フェーズ概要ページ用
└── js/
    ├── data.js       # ★カリキュラムの一元管理データ（52ユニットの定義）
    └── main.js       # 目次描画・ユニットタブ・前後リンク・図の拡大
```

## 目次の仕組み（重要）

カリキュラムの情報源は **`js/data.js` のみ**。

- `PHASES`: 4フェーズのメタ情報（期間・英語名・概要ページのファイル名）
- `P1`〜`P4`: 各13ユニットを `"タイトル|トピック"` の形式で定義
- ユニットのファイル名は自動生成 → `p{フェーズ番号}-{01〜13}.html`
- 状態: 第3要素で指定。省略時は `plan`（予定）
  - `plan` = 予定 ／ `wip` = 制作中 ／ `done` = 公開中

index.html の目次も、ユニットページ上部のタブ・下部の前後リンクも `data.js` を見て自動描画される。
`main.js` はユニットが「公開中 or 制作中」のときだけリンクを張り、それ以外は「予定」表示にする。

## 新しいユニットを公開する手順

1. ユニットページ `pX-YY.html` を作成する
   - `<body data-file="pX-YY.html">` を付ける（タブ・前後リンクが有効になる）
   - `<div id="lesson-tabs">`（ユニット上部）と `<nav id="pager">`（ページ下部）を置く
   - クイズを入れる場合は既存パターン（`.quiz-q` / `.opt[data-correct]` / `js/quiz.js`）に従う
2. `js/data.js` の該当ユニットに `"|done"` を追記（末尾の第3要素）
3. 目次・タブ・前後リンクへ自動反映される（index 再読込で確認）

## ページ共通の型（ユニットページの見出し構成）

1. `goal` ボックス … このUnitでできるようになること
2. 本文（Step単位で分割。コード・図・式は具体例とセットで）
3. 途中確認クイズ（`.mini-q`）＋章末クイズ
4. 「今日学んだこと」を自分の言葉で書く欄

## デザイン

「紙（クリーム）× 紺 × ブラス(金具)」のマーケット・デスク・ノート風。
CSSは `css/*.css` の `:root` 変数を変えるだけで配色変更できる。
