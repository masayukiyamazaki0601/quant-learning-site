## 1. 数字の「並び」と「表」：ベクトルと行列

### 1-1 具体例：さくらコーヒーの「2店舗の売上表」

「さくらコーヒー」には新宿店と池袋店があります。ある日の売れた数を表にすると……

| 店 | コーヒー（杯） | ケーキ（個） |
| --- | --- | --- |
| 新宿店 | 300 | 150 |
| 池袋店 | 200 | 100 |

この「四角く並んだ数字の表」を、数学では **行列（ぎょうれつ）** と呼びます。エクセルで言うと、四角い範囲のセルをイメージしてください。

そして、1列だけの数字の並び、たとえば

- 新宿店の売上 ＝ コーヒー300、ケーキ150 → **ベクトル**「[300, 150]」
- 池袋店の売上 ＝ [200, 100]

この「1列に並んだ数字」を **ベクトル** と呼びます。エクセルで言えば1列分です。

> 覚える1行：**ベクトル＝数字の並び、行列＝数字の表**（行列はベクトルを何本か並べたもの）

### 1-2 行列の足し算は「同じ場所どうし」を足すだけ

火曜日の売上が、新宿店 [320, 160]、池袋店 [210, 105] だったとします。月曜と火曜を合計するときは、**それぞれ同じ場所どうしを足すだけ**です。

- 新宿店：300+320=620、150+160=310 → **[620, 310]**
- 池袋店：200+210=410、100+105=205 → **[410, 205]**

「位置をそろえて足す」、それだけです。難しいことは何もありません。

### 1-3 行列×ベクトル＝「表とリストの掛け算」で、売上金額が出る

次は、行列を使うと何がうれしいのか。コーヒーの単価が300円、ケーキの単価が450円とします。単価を並べたベクトルは **[300, 450]** です。

新宿店の売上金額を求めるとき、中学の知識だけで次のように計算できます。

\[
300 \times 300 + 150 \times 450 = 90000 + 67500 = \mathbf{157500円}
\]

つまり「コーヒーの杯数×単価」＋「ケーキの個数×単価」。並びの**順番をそろえて、掛けて、全部足す**。これを数学では「ベクトルの**内積（ないせき）**」と呼びます（高校〜大学の言葉。今は「順番に掛けて全部足す」でOK）。

池袋店は 200×300 + 100×450 = **105,000円**。この「2店舗の売上金額」を、行列とベクトルの掛け算1発でまとめて出せる——それが行列のうれしさです。

### 1-4 Pythonで確かめる：リストをまとめて計算する

```python
import numpy as np

# 行列：行＝店、列＝商品（コーヒー、ケーキ）
sales = np.array([
    [300, 150],   # 新宿店
    [200, 100]    # 池袋店
])
# ベクトル：単価（コーヒー300円、ケーキ450円）
price = np.array([300, 450])

# 行列 × ベクトル ＝ 店ごとの売上金額
print(sales @ price)
```

```text
[157500 105000]
```

1行の計算で「新宿157,500円・池袋105,000円」がまとめて出ました。**「並び」と「表」の形のまま計算する**のがNumPyの流儀で、この先のデータ分析（フェーズ3以降）で毎日使います。

## 2. 債券計算：デュレーションで「金利への弱さ」を数字にする

### 2-1 債券の受け取りを「ベクトル」で並べる

第2週で出てきた債券（額面100万円）を、今度は**年5%のクーポン（利子）付き・満期10年**にしてみましょう。

もらえるお金を年ごとに並べると……

| 1年目 | 2年目 | 3年目 | … | 9年目 | 10年目 |
| --- | --- | --- | --- | --- | --- |
| 5万円 | 5万円 | 5万円 | … | 5万円 | 5万＋100万＝105万円 |

この「[5, 5, 5, …, 105]」という**並びが、まさにベクトル**です。第1章でやった「数字の並びをまとめて扱う」道具が、さっそく登場しました。

### 2-2 現在価値で「重み付け」する（第3週の復習）

でも、1年後の5万円と10年後の105万円は、そのまま足してはいけません。**遠いお金ほど現在価値が小さい**んでしたね（第3週）。

金利5%のとき、それぞれを (1+0.05)^t で割って「いまの価値」に直すと：

| 年目 | 受け取り | いまの価値 |
| --- | --- | --- |
| 1年目 | 5万円 | 約4.76万円 |
| 2年目 | 5万円 | 約4.54万円 |
| … | … | … |
| 9年目 | 5万円 | 約3.22万円 |
| 10年目 | 105万円 | **約64.46万円** |
| **合計** | | **約100.0万円** |

この合計こそが「この債券のいまの値段（価格）」です。**価格＝もらえるお金の現在価値を全部足したもの**。第3週の考え方そのままですね。

### 2-3 デュレーション＝「お金が返ってくるまでの重み付き平均」

ここからが今回のメインです。上の表を見てください。**1年目にもらえる4.76万円もあれば、10年目にもらえる64.46万円もあります**。つまり「この債券のお金は、いったい平均すると何年後に返ってくるのか？」という疑問が生まれます。

答えの計算はとても素直です。**「それぞれの現在価値を重みとして、年数を平均する」**。

- 1年目の4.76万円には「1年」を掛ける
- 10年目の64.46万円には「10年」を掛ける
- それを全部足して、合計の100万円で割る

すると、この債券の答えは **約8.1年** になります。この数字が **デュレーション** です（満期が10年なのに8.1年と短くなるのは、毎年5万円ずつ先にお金が返ってくるから。「平均すると8.1年後にお金が返ってくる債券」という意味）。

??? example "大人の式（クリックで表示。開かなくてOK）"
    \[
    \text{デュレーション} = \frac{\sum (\,t \times \text{t年目の現在価値}\,)}{\text{現在価値の合計（＝価格）}}
    \]
    意味は「年数 t を、現在価値の大きさで重み付けして平均したもの」。\(\sum\) は「全部足す」の記号です。

### 2-4 動く図で見る：金利が上がると、2本の債券の価格はどうなる？

まず、2本の債券を用意します。

- **債券A**：毎年5万円もらえる10年債（デュレーション≈8.1年）
- **債券B**：10年後に100万円を一括でもらえる債券（デュレーション=10年）

| 世の中の金利 | 債券A（毎年5万円） | 債券B（10年一括） |
| --- | --- | --- |
| 1% | 137.9万円 | 90.5万円 |
| 5% | 100.0万円 | 61.4万円 |
| 10% | 69.3万円 | 38.6万円 |

見てほしいことは2つだけです。

1. **金利が上がると、どちらの債券も価格が下がる**（右肩下がり）
2. **下がり方は債券Bのほうが大きい**。Bは 90.5万円 → 38.6万円（約58%減）。Aは 137.9万円 → 69.3万円（約50%減）

なぜBのほうが大きく下がるのか？ Bは「10年後のお金」だけでできているからです。遠いお金ほど金利の影響を受けやすい——さっきの2-3でやった**デュレーションが長いほど金利に弱い**、がまさにこの図になっています。

### 2-5 Pythonで確かめる：価格とデュレーションを計算する

```python
def bond(r):
    price = 0
    weighted = 0
    for t in range(1, 11):
        cf = 105 if t == 10 else 5   # 毎年5万円＋10年目に額面100万円
        pv = cf / (1 + r) ** t
        price += pv
        weighted += t * pv
    return price, weighted / price   # (価格, デュレーション)

for r in [0.01, 0.05, 0.10]:
    price, dur = bond(r)
    print(f"金利{r * 100:>3.0f}% → 価格≈{price:6.1f}万円 / デュレーション≈{dur:.2f}年")
```

```text
金利  1% → 価格≈ 137.9万円 / デュレーション≈8.43年
金利  5% → 価格≈ 100.0万円 / デュレーション≈8.11年
金利 10% → 価格≈  69.3万円 / デュレーション≈7.66年
```

金利が1%→10%に上がると、価格は **137.9万円 → 69.3万円**。金利上昇で債券価格は下がる（第2・3週のシーソーの確認です）。

### 2-6 デュレーションの使い方：「金利が1%動いたら価格はおおよそ?%動く」

デュレーションは、こんなふうに使います。

> **金利が1%動いたとき、債券価格はおおよそ「デュレーションぶんの%」動く**

- 毎年5万円もらえる10年債（デュレーション≈8.1年）→ 金利が1%上がると価格は**おおよそ8%下落**
- 10年後に一括で100万円もらえる債券（デュレーション=10年）→ **おおよそ10%下落**

「お金が返ってくるのが遅い（デュレーションが長い）債券ほど、金利の変化で価格が大きく動く」。だから、金利が上がりそうなときは**短い債券や利子が多めの債券**で守り、金利が下がりそうなときは長い債券で値上がりを狙う——という運用の話につながります。デュレーションは「債券の値動きの大きさをはかる物差し」です。

??? example "大人の式（クリックで表示。開かなくてOK）"
    正確には「修正デュレーション」を使って、
    \[
    \frac{\text{価格の変化}}{\text{価格}} \approx -\frac{\text{デュレーション}}{1+r} \times \Delta r
    \]
    今は「デュレーション≈価格が何%動くかの目安」という理解でOK。細かい式はフェーズ2以降で。

    - 金利が上がると債券価格は＿＿＿。デュレーションが長いほど、動きは＿＿＿。
