# フェーズ1：数学・統計・Python・市場の土台（第1〜13週）

> Phase 01 / Foundations — 以後すべての理論・実装を支える4本柱（数学・統計・Python・金融の言葉）を固める3ヶ月。

## 到達目標

- 大学初〜中級レベルの微積分・線形代数・確率・統計で演習問題を解ける
- Python（NumPy/Pandas）で金融データを取得・分析・可視化できる
- 債券・先物・オプションの定義とペイオフを説明できる（Hull 前半相当）
- ポートフォリオのリターン・リスク・最小分散をスクラッチで計算できる

## 時間配分の目安

| 区分 | 割合 | 内容 |
| --- | --- | --- |
| 理論（数学） | 45% | 微積分 → 線形代数 → 確率 → 統計（各週1テーマ） |
| 理論（金融） | 15% | 市場構造・時間価値・債券・オプションの基本 |
| 実装（Python） | 25% | その週の内容を NumPy / Pandas で再現 |
| 課題・復習 | 15% | 週次課題＋第13週の総復習 |

## 主なトピック

- **数学**：1変数・多変数微積分（Taylor 展開・偏微分）／線形代数（行列・固有値・SVD）／確率論（条件付き確率・分布・CLT）／統計（推定・検定・線形回帰）
- **金融**：市場の全体像／貨幣の時間価値・利回り・デュレーション／リターンの統計的性質／ポートフォリオ基礎／先物・オプションの定義
- **実装**：Python 環境・Git／NumPy／Pandas／可視化／データ取得（yfinance）／scipy.stats・statsmodels

## アウトプット課題

1. **銘柄リターン分析レポート**：複数ETFのリターン・ボラティリティ・相関・βを計算し可視化（再現スクリプト付き）
2. **最小分散ポートフォリオ**：NumPy の線形代数だけで実装し、効率的フロンティアを描く
3. **債券計算モジュール**：価格・利回り・デュレーション計算＋t検定を1パッケージ化
